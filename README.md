# Media Hub

Plataforma de aquisição, download, transcrição e futura análise de conteúdo multimídia, iniciando pelo YouTube.

## Primeiro incremento

O Web MVP inicial terá:

- API com FastAPI;
- interface web simples em HTML, CSS e JavaScript;
- envio de URL pública do YouTube;
- download do áudio com yt-dlp e FFmpeg;
- transcrição local com faster-whisper;
- acompanhamento do status do processamento;
- visualização da transcrição;
- download de MP3, TXT, SRT e JSON.

## Uso responsável

Utilize somente conteúdo próprio, autorizado ou cujo processamento seja permitido pela legislação e pelos termos aplicáveis. O projeto não deve contornar DRM, autenticação, restrições territoriais ou outros controles de acesso.
